## 为 Buddy2API 保留或调整的差异

- 保留包名、应用标识、`~/.buddy2api` 数据目录、统一域名、更新签名、现有主题及 2API/模型页面。新增 hook 和备份模块使用 Buddy2API 存储目录。
- 保留代理监听、路由、自动刷新和 `CodeBuddyIDE/4.11.2 CodeBuddy/4.11.2` UA。
- 上游以 UID 唯一为前提，直接移植会把同手机号不同组织的限额错误归属到首条或末条账号。UID 映射仅接受唯一匹配；WorkBuddy hook 先限定档位；无法区分组织时不猜测，保留可用的会话/状态归因路径。
- 同 UID 的组织共享会话，复制返回跳过说明；保留组织字段和目标账号名称。同步仍由后端同 UID 检查阻止写入。
- 加密信封重导入除了保留未过期 access token，也保留仍可刷新、或未记录刷新到期时间的明文 OAuth 凭据，避免 2API 失去续期能力。仅有加密信封的账号仍不能直接用于 2API，上游未提供信封解密能力。
- 不接入上游禁用国际版签到的策略：保持尝试请求，未开放按 inactive 处理；成长中心入口也保持原策略。
- 保留 CNB 同步配置、停用 Pages 与 npm 发布的现状。本次不采用上游默认开启 npm 发布的变量策略，不直接操作 GitHub。
- 集成时保留本项目版本 0.1.41；随后按发布要求统一更新为 0.1.45，并发布标签 v0.1.45，避开上游已有的 v0.1.42～v0.1.44 标签。
